# 八爪鱼 MCP 调研记录

> 调研时间：2026-05-19
> 结论：作为 AI 数据获取工具，与全能内容理解技能互补

---

## 八爪鱼是什么

**产品定位**：八爪鱼 RPA + MCP 服务，让 AI 直接从网页提取结构化数据

**官网**：https://www.bazhuayu.com

**MCP 是什么**：Model Context Protocol — AI 与外部工具通信的协议标准。八爪鱼 MCP = 八爪鱼的爬虫能力通过 MCP 协议暴露给 AI 调用。

---

## 工作原理

```
用户（和 AI 对话）："帮我查一下某网站房价数据"
    ↓
AI 调用八爪鱼 MCP
    ↓
八爪鱼自动：打开网页 → 提取数据 → 返回结构化结果给 AI
```

**支持 AI 工具**：ChatGPT、Claude（Desktop）、Cursor、Gemini 等

---

## 能做什么

- 实时价格监控（电商、房价、股价）
- 竞品数据采集
- 舆情监控
- 招聘/房产/招投标信息聚合
- 任何网页数据的结构化提取

---

## 对全能内容理解的补充

| 维度 | 全能内容理解 | 八爪鱼 MCP |
|------|------------|-----------|
| 核心能力 | 视频/图文理解 + AI 分析 | 结构化数据提取 |
| 交互方式 | 我主动提取 → LLM 分析 | AI 主动调用 → 实时爬取 |
| 数据形式 | 字幕/截图/LLM 总结 | 表格/JSON/结构化字段 |
| 适用场景 | 视频内容理解、帖子分析 | 数值型数据监控、批量采集 |

**两者可互补**：用八爪鱼 MCP 做数据采集 → 用全能内容理解的 LLM 做深度分析
