# 抖音平台内容提取已知限制

> 2026-05-18 实测记录

## 核心发现

### 1. 图文帖（note）与视频帖内容结构不同

抖音有两种主要内容页：

| 类型 | URL特征 | 内容提取结果 |
|------|---------|-------------|
| **视频帖** | `/video/数字` | 标题+描述+统计信息，Playwright 可完整提取 |
| **图文帖** | `/note/数字` | **仅有简短引言**，GitHub链接等详情内容在页面HTML中不可见 |

图文帖页面（`/note/`）的正文内容只显示类似这样的引言：
```
"Codex代理方法。大家好，我是指北师！上一条内容我分享了...今天我就把这个方法开源到GitHub了"
```
实际的完整图文内容（可能包含GitHub链接）需要**登录后打开抖音APP**才能看到，或者通过**评论区**间接获取。

### 2. 图文帖提取失败时的解决思路

当 `extract_with_playwright()` 拿到的是"视频去哪了呢"占位页 or 内容极少（标题+版权信息），排查顺序：

```
① 先确认是不是图文帖（/note/ URL）
  └→ 是 → 当前方法只能获取引言，无法获取正文详情
② 若需要GitHub链接/完整图文内容：
  → 方案A：在评论区查找链接（图文帖评论区可能有作者回复）
  → 方案B：通过作者名字+关键词在GitHub搜索项目
  → 方案C：让用户直接发完整截图/内容
③ 若需要做项目调研：
  → 从页面可见的作者名+项目关键词 → GitHub搜索
  → 例："指北师"+"Codex"+"Deepseek" → 搜到 Nigel211/codex_deepseek_proxy
```

### 3. 图文帖的判断

```
URL含 /note/ → 图文帖，Playwright只返回引言+页脚
URL含 /video/ → 视频帖，Playwright可返回完整描述+统计
```

### 4. 视频帖的 extra_wait

部分视频页在 `domcontentloaded` 后还在重定向（如"视频去哪了呢"占位），需要 `extra_wait=3` 才能拿到真实标题。

> 失效视频（旧链接/审核删除）会跳转到占位页，标题为"视频去哪了呢？_哔哩哔哩_bilibili"，正文只有3秒跳转脚本。这是链接已失效，不是代码问题。

## GitHub项目发现工作流

```
收到抖音链接 → 判断是note还是video
  ├─ /note/ → 只拿到引言 → 用引言中的关键词搜GitHub
  └─ /video/ → 完整提取
```

在GitHub搜索时用 `site:github.com 关键词` 或 GitHub搜索API（需认证），搜不到就换关键词组合（项目名、作者名、技术栈）。
